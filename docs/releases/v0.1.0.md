Mac Monitor 首个开源版本，原生支持 Apple Silicon，最低系统版本为 macOS 14。

- 菜单栏 CPU / GPU / 内存 8 段柱图，三种颜色区分。
- 弹窗内查看三个维度的 Top 5 及完整进程列表。
- 隐藏维度、刷新频率和百分比显示设置自动保存。
- 无主窗口、无 Dock 图标、无自动输入焦点。
- 缓存排序和菜单栏图像，历史只保留整机数值。
- 关闭弹窗或进入设置后停止进程扫描；单一维度页面只采样相关进程数据。

下载 `MacMonitor-v0.1.0-arm64.dmg` 后拖入 Applications，或使用 ZIP 中的应用。`.sha256` 文件可用于校验下载完整性。

本版本使用 ad-hoc 签名，尚未配置 Developer ID 签名和 Apple 公证；系统可能限制首次打开。也可以按 README 从源码构建。GPU 逐进程统计依赖驱动字段，系统未提供数据时会显示不可用。
