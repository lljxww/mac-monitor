Mac Monitor v0.2.0：同心圆菜单栏图标与可配置的指标布局。

- 默认外环显示内存、内环显示 CPU，中心小数字显示 GPU 占用百分比。
- 圆环保留完整的淡色底轨，已用部分以对应颜色的弧线填充；零占用时也能看到完整轮廓。
- 在「设置 → 菜单栏布局」中为外环、内环和中心数字选择 CPU、GPU 或内存，并实时预览。
- 选择其他位置正在使用的指标时自动交换位置，颜色跟随指标；布局自动保存，重启后保留。
- 保留隐藏指标、1/2/3/5 秒刷新间隔，以及在图标旁显示完整百分比的选项。

支持 Apple Silicon，最低系统版本为 macOS 14。

下载 `MacMonitor-v0.2.0-arm64.dmg` 后将应用拖入 Applications，或使用 ZIP 中的应用。下载目录中的 `.sha256` 文件可用于校验安装包。

通过 Homebrew 更新或安装：

```bash
brew update
brew upgrade --cask mac-fantasy/tap/mac-monitor
# 首次安装
brew install --cask mac-fantasy/tap/mac-monitor
```

验证：13 项核心测试、28 项应用内检查通过，并检查浅色和深色界面，以及零占用、满占用和数据不可用时的图标渲染。

本版本使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证；首次打开方式见 README。GPU 逐进程统计依赖驱动提供的数据。
